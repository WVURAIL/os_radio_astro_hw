# Original June 22, 2018 assembly sources

Pranav Sanghavi's original DSPIRA LNA assembly source and figures are retained here for reference.
Use the maintained [PDF](../assembly-guide-2018-06-22.pdf) or [editable Word guide](../assembly-guide-2018-06-22.docx) for teaching.
These raw historical files keep the original wording, component values, author credits, and diagram resolution.
Match component values to your board revision.

## Source and changes

Imported from [WVURAIL/memos, commit `8da9c9a522b3934222913d00c295ffaf49cda47d`](https://github.com/WVURAIL/memos/tree/8da9c9a522b3934222913d00c295ffaf49cda47d/2018_06_22).
All original paths below are relative to its `2018_06_22/` directory.
The LaTeX and style files were renamed, and only the package name in `\usepackage` and `\ProvidesPackage` changed.
The two PNG files retain their original bytes. No PDF was regenerated from these sources.
