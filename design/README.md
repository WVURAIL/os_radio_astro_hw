# Amplifier design files

| File | Purpose |
| --- | --- |
| [amplifier-v3.pdf](amplifier-v3.pdf) | Version 3 schematic, readable without Altium |
| [Altium schematic](altium/HI_Amplifer_schematic.SchDoc) | Editable schematic source |
| [Altium PCB layout](altium/HI_Amplifier.PcbDoc) | Editable board layout |

The PCB stores references to `HI_Amplifer_schematic`, including that original spelling.
Both native filenames remain unchanged to preserve those associations.
Their mixed case is limited to this source pair; ordinary filenames elsewhere use lowercase and hyphens.

The repository contains standalone Altium documents, without an Altium project file.
Changes to their internal associations should be made and checked in Altium.

See the [design overview](../docs/design-overview.md), [fabrication files](../fabrication/), and [assembly references](../assembly/).
